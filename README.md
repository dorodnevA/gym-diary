# Дневник тренировок

Приложение для учёта рабочих весов по программе на массу (3 дня в неделю: вт, чт, вс).

- Ввод рабочего веса по каждому упражнению, сохранение тренировки с праздничной анимацией
- Добавление, удаление и редактирование упражнений (название, мышечная группа, подходы, повторения)
- Календарь тренировок с пометками «В», «Н+Р», «В+Н» и удалением записей
- Гистограмма прогресса по каждому упражнению
- Работает офлайн (PWA), данные хранятся на телефоне; есть выгрузка и загрузка копии данных

Сайт публикуется через GitHub Pages из ветки `main`. APK для Android собирается из адреса сайта на pwabuilder.com.
